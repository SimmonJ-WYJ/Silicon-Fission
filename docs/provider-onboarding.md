# 模型供应商接入指南(新人 Onboarding)

> 面向对象:负责渠道/供应商对接的同事。
> 目标:读完这份文档,你能独立完成「找到一家模型供应商 → 申请 API Key → 在硅基裂变后台配好 → 测通 → 让用户能调用」的全流程。
> 预计上手时间:30 分钟。

---

## 0. 你的角色是什么

硅基裂变是一个**大模型 API 中转站**:我们不训练模型,而是把各家模型厂商(上游)的 API 聚合起来,统一转卖给用户。

你的核心工作就是**接入"渠道"**:
- 去某家模型厂商(如 DeepSeek)注册、拿到他家的 API Key
- 把这个 Key 配进我们的后台,并声明"这个渠道能提供哪些模型"
- 测试连通,确认用户能通过我们的平台调用到该模型

一个"渠道 = 一家上游的一个 Key + 它能跑的模型列表"。渠道越多越稳(某家挂了可以自动切换到另一家)。

---

## 1. 五分钟快速上手(以 DeepSeek 为例)

1. 打开 https://platform.deepseek.com ,注册/登录
2. 左侧菜单 **API Keys → 创建 API Key**,复制那串 `sk-...`(**只显示一次,务必立刻保存**)
3. 账户里**充点钱**(¥10 起,否则调用会报余额不足)
4. 打开我们的平台 → **渠道配置** 页(`/admin`)
5. 「接入新渠道」里点预设 **DeepSeek** → 粘贴刚才的 Key → 点「接入渠道」
6. 在渠道列表点「测试连通」,显示绿色即成功
7. 去 **控制台** 建一个 sk- Key → 去 **对话** 选 `deepseek-chat` 发一句话,能回就全通了 ✅

其他供应商流程一样,区别只在**注册地址、Base URL、模型名、是否需要出海线路**——见下表。

## 3. 通用:如何从一家供应商拿到 API Key

不管哪家,套路都一样:

1. **注册账号**:用邮箱/手机号注册控制台
2. **实名/充值**:国内厂商通常要实名认证;几乎都要**先充值/领取免费额度**,否则调用报错
3. **创建 API Key**:在控制台找 “API Key / 密钥 / API-KEY 管理” 菜单,点创建
4. **立即保存**:Key 一般**只在创建时完整显示一次**,离开页面就只能看到打码版。存到密码管理器
5. **(可选)记下模型名**:在“模型列表 / 模型广场 / 文档”里抄下你要开放的模型的**准确名称**(大小写、连字符都要一致)
6. **(重要)看清限速**:文档里会写 RPM(每分钟请求数)/ TPM(每分钟 token 数)。免费/新账号限速很低,量大要提工单或找商务提额(见第 5 节)

## 4. 在硅基裂变后台配置渠道

### 方式 A:用我们的 `/admin` 页面(推荐,适合 OpenAI 兼容渠道)

1. 登录管理员账号,打开 **渠道配置**(`/admin`)
2. 「接入新渠道」区域:
   - **上游预设**:点对应厂商(DeepSeek / SiliconFlow / Moonshot / OpenAI),会自动填好 Base URL 和推荐模型;没有的选「自定义」
   - **渠道名称**:起个好认的名,如 `DeepSeek-主`
   - **上游 Base URL**:见第 2 节表格(用预设会自动填)
   - **上游 API Key**:粘贴你申请到的 `sk-...`
   - **开放的模型**:逗号分隔,如 `deepseek-chat,deepseek-reasoner`。**这里写的名字必须和上游模型名一致**
3. 点 **接入渠道**
4. 在上方渠道列表点 **测试连通**,绿色即成功

### 方式 B:用 new-api 完整后台(适合 Claude/Gemini 原生等高级配置)

打开 `http://<你的后端地址>:3000` → 登录 → 左侧 **渠道 → 创建渠道**:
- **类型**:选对应厂商(OpenAI / Claude / Gemini / 通义 / 智谱 …)
- **密钥**:粘贴 API Key
- **模型**:选择或填入该渠道支持的模型
- **分组**:一般 `default`(决定哪些用户能用)
- 保存后点「测试」,再点「启用」

> 两种方式配的渠道数据是同一个后端,互通。日常接 OpenAI 兼容渠道用 A 更快;要用非兼容协议或调倍率/权重/代理等细项,用 B。

## 5. 联系与对接指南(找供应商要资源)

当一家渠道要**上量**(正式给用户用),免费额度和默认限速往往不够,需要主动联系供应商。

### 5.1 联系渠道有哪些

1. **控制台工单 / 客服**:最常用。控制台一般有“工单 / 帮助 / 联系我们”,技术问题走这里
2. **商务合作 / 企业销售(BD)**:提额、折扣、发票、SLA 这类走商务。找法:
   - 官网底部“商务合作 / 企业服务 / 联系销售”
   - 控制台内“企业版 / 升级”入口
   - 官方文档或公众号留的商务邮箱
3. **官方社群**:很多国产厂商有开发者微信群/钉钉群,响应快

### 5.2 联系时要问清楚的事(照着问)

- **提高限速**:把 RPM / TPM / 并发提到我们预估的峰值(带上预估日调用量)
- **企业折扣 / 阶梯价**:量大能否谈更低单价
- **发票**:能否开票、税率、对公转账
- **是否允许转售 / 二次分发**:⚠️ **最关键**——明确我们是"聚合转卖"场景,确认其 ToS 是否允许,避免封号
- **稳定性**:是否有 SLA、专属通道、故障通知渠道
- **计费与账单**:怎么查账、余额预警、欠费策略

### 5.3 一封对接邮件的模板

```
主题:企业 API 接入与商务合作咨询 —— 硅基裂变

您好,

我们是「硅基裂变」大模型 API 聚合平台,希望接入贵司的 [模型名] 并对我们的
用户提供服务。目前有以下几点想确认:

1. 提额:我们预估日调用约 [X] 万次 / 峰值 [Y] RPM,当前账号限速偏低,能否提额?
2. 商务价格:是否有企业阶梯价 / 折扣?
3. 合规:我们是聚合转售场景,贵司 ToS 是否允许 API 二次分发?
4. 发票与结算:能否对公开票?

我方联系人:[姓名 / 微信 / 邮箱]
期待回复,谢谢!
```

## 6. 如何合法拿到低成本渠道

降本是应该的,但**要用正当方式压低成本,而不是去买来路不明的低价货**。下面这些方法既便宜又干净,不会让公司暴雷。

### 6.1 先记住一条红线

> **凡是"远低于官方价的 GPT / Claude"都别碰。** 便宜一定有代价:要么是挂着 `gpt-4o` 的名、后台偷偷路由到廉价小模型(等于欺骗我们自己的用户);要么是盗刷号、泄露 Key、白嫖号池(等于转售赃物,随时封号 / 被追责 / 卖家跑路)。
>
> 这类货常见于 Telegram / QQ 匿名群,靠"低价 + 靠谱"引流。**一律不接入、不采购、不写进渠道台账。** 发现有人推,直接拒绝。

判断口诀:**价格明显低于上游官方价,就一定有人在违规**——不是违 ToS,就是盗号,或是模型造假。省下的那点钱,远不够赔一次暴雷。

### 6.2 正道一:优先用本来就便宜的国产模型

国产旗舰现在便宜到没必要冒险(单价以官方为准,量级示意):

| 模型 | 大致输入价 | 适用 |
|---|---|---|
| DeepSeek V3 | ~¥0.27 / 百万 token | 通用主力,性价比标杆 |
| Qwen-Turbo / GLM-Flash | 更低,部分近乎免费 | 高频、简单任务 |
| Kimi / MiniMax 低配档 | 低 | 长文本、特定场景 |

优先把这些做成主力渠道,成本天然就低,还全部国内直连、合规。

### 6.3 正道二:聚合商一个 Key 拿多模型

- **SiliconFlow(硅基流动)**:国内,一个 Key 覆盖 DeepSeek / Qwen / GLM 等多家开源模型,官方直连、价格透明。
- **OpenRouter**:海外,400+ 模型统一接口,按官方列表价透传。
适合快速铺量、省去逐个注册。

### 6.4 正道三:找官方商务谈折扣(最有效)

上量之后,**同一份官方渠道也能变便宜**:
- 走商务谈**企业阶梯价 / 折扣**(见第 5 节邮件模板)
- 承诺月度用量 / 预充值,换更低单价
- 这是把成本压下来的正道,且拿到的还是真模型、真官方通道

### 6.5 正道四:技术手段降本

- **Batch 批量接口**:OpenAI、DeepSeek 等的异步批量 API,单价通常打大折扣,适合非实时任务
- **Prompt 缓存**:命中缓存的输入 token 大幅便宜,长上下文场景省很多
- **模型分级路由**:简单任务路由到便宜小模型,难任务才上旗舰,平均成本下降
- **自托管开源模型**:量特别大时用 GPU 跑开源模型,边际成本最低

### 6.6 低成本采购 Checklist

- [ ] 该渠道是**官方直连 / 正规聚合商**吗?(不是 → 不接)
- [ ] 价格是否在官方价合理区间?(远低于官方 → 警惕造假 / 盗号)
- [ ] 模型身份可核验吗?(接入后用已知问题对比输出,防挂羊头卖狗肉)
- [ ] 有正规发票 / 对公结算吗?
- [ ] 是否已优先考虑国产便宜模型 + 商务折扣,而非灰产低价?

## 7. 上线前必须知道的风险

1. **上游封号**:境外厂商(OpenAI/Anthropic/Google)官方不服务中国大陆,转售其额度**违反 ToS,渠道可能被封**。对策:多渠道冗余、监控可用性、备用号。
2. **国内合规**:面向公众提供未备案的境外大模型,处于监管灰色地带。自行评估法律风险。
3. **Key 安全**:API Key 等于花钱的权限,**绝不外泄、不进代码仓库、不发群里**。发现泄露立即在上游控制台吊销重建。

详见 [docs/deployment.md](deployment.md)。

## 8. 常见报错排查

| 现象 | 可能原因 | 解决 |
|---|---|---|
| 测试连通失败 / 401 | Key 错、过期、被吊销 | 核对 Key,必要时上游重建 |
| 余额不足 / 402 | 上游账户没充值 | 去上游控制台充值 |
| 模型不存在 / 404 | 模型名写错(大小写/连字符) | 对照上游文档改「开放的模型」 |
| 429 限速 | 触发上游 RPM/TPM | 找商务提额,或加多个同类渠道分摊 |
| 境外渠道超时 | 服务器出不了海 | 服务器放境外,或给该渠道单配代理 |
| 模型价格未配置 | 后台未开自用模式/未配价 | new-api 后台开「自用模式」或配模型价格 |

## 9. 接入一个新渠道 —— Checklist

- [ ] 在上游官网注册账号并完成实名(国产)
- [ ] 账户已充值 / 已领免费额度
- [ ] 创建 API Key 并安全保存
- [ ] 记录准确的 Base URL 和模型名
- [ ] 在 `/admin` 或 new-api 后台创建渠道并填入
- [ ] 点「测试连通」通过
- [ ] 用测试 Key 在对话页实际调一次成功
- [ ] 记录该渠道的限速上限,评估是否需要找商务提额
- [ ] (上量前)与供应商确认转售 ToS、发票、折扣
